## Attack pass (beyond the plan's list)

- **IDOR / parameter substitution** — both endpoints take no arguments; the subscription is resolved from
  the admin-side session (`api/account.py:1042-1045 current_customer()`). No handle a caller can aim.
  Defended.
- **Auth bypass** — `require_jarvis_admin()` runs before the admin round trip and is asserted to (see
  edge 4). Both endpoints are in `GATED_ENDPOINTS`. Defended.
- **Secret leakage** — `admin_client` strips credential-shaped keys; `augment_pay_page` adds only
  `pay_origin` / `pay_origin_attested`; the raw token rides only in the URL fragment
  (`paymentMachine.js:429`). Defended.
- **Resource** — unbounded provider calls: **finding 7**. `_bust_chat_gate` is a Redis KEYS scan and its
  own docstring forbids hot-path use; it fires on every successful Check. Human-triggered, so within its
  stated budget today — but it becomes a hot path the moment anything polls the healer, and nothing
  stops that.
- **Migration on real-shaped data** — patch is a single guarded UPDATE, never touches `status`, no doc
  cache to invalidate (no `get_cached_doc("Jarvis Subscription")` anywhere in admin). Defended.
- **Money/precision, time** — no arithmetic added; entitlement uses the existing ceil-days helper.

VERDICT: RED
