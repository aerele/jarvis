## Attack pass (playbook)

| Attack | Result |
|---|---|
| Empty / null / whitespace in every new param | `limit` 7 bad forms all clean-error. `values` non-dict/empty rejected. `doctype` null/unknown rejected. Whitespace value → **BLOCKER-1**. |
| Oversized / deeply nested input | 2000-row child table → 200, 2000 records, 367 KB, sub-second. 12-level nesting → capped at `_MAX_VALUE_DEPTH`, no `RecursionError`. `_MAX_VALUE_DEPTH = 8` cannot reject a legitimate payload: a choice value nests at most 2 (list of candidate dicts). |
| Wrong types | dict / list-of-dict / int / float / bool all reach the agent — but see MAJOR-2 for the status. |
| Hostile strings | `' OR 1=1 --`, `%`, RTL + zero-width unicode → echoed verbatim, `missing`, no injection (choice matching is pure Python; `doctype` goes through parameterised `frappe.db.exists`). |
| Auth: unauthenticated / low-privilege | Guest rejected at api.py:119; non-Jarvis user rejected at api.py:127. |
| Auth: enumeration oracle over an option list | Blocked — `unchecked`, no candidates, no count, verified live on two genuinely unreadable doctypes as a non-Administrator. |
| Auth: does removing the child gate reopen anything | No. Child option lists are metadata `get_schema(verbose=True)` already serves under the parent's gate (get_schema.py:308-310, 320-321). |
| Failure injection: `has_permission` raising | **Breaks — MAJOR-3.** |
| Failure injection: malformed metadata | Sweep of all 308 doctypes carrying choice fields, each with every choice field poisoned and every child table given `[{"__x":1}, "notadict", {"a":{"b":[{"c":1}]}}]`: 1 failure, and it is MAJOR-3. |
| Resource: unbounded loops / growth | `choices` grows with caller input only, no cap — same shape as the pre-existing `links`. Logged as a MINOR-level property, no leak, no unbounded server-side state. |
